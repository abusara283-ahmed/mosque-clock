# قائمة تجربة التطبيق على أجهزة حقيقية

ضع ✓ أمام كل بند. يكفي جهازان أو ثلاثة: صندوق تلفاز، وجوال حديث (أندرويد ١٤ أو أحدث)، وجهاز قديم (أندرويد ٧ أو ٨) إن وُجد.

## شاشة المسجد (صندوق تلفاز أو تابلت معلّق)
- [ ] أول تشغيل: تظهر شاشة الاختيار و«شاشة المسجد» مقترحة، وتمضي وحدها بعد ١٥ ثانية.
- [ ] الساعة بملء الشاشة بلا أشرطة النظام، والشاشة لا تنطفئ بعد ٣٠ دقيقة.
- [ ] الريموت: «موافق» يفتح القائمة، الأسهم تتنقل، الإعدادات تُفتح وتُحرَّر بالريموت.
- [ ] الأذان والإقامة يُسمعان بلا لمس (جرّب بتقديم ساعة الجهاز دقيقتين قبل صلاة).
- [ ] منح «الظهور فوق التطبيقات» ثم **فصل الكهرباء وإعادتها**: تفتح الساعة وحدها.
- [ ] فتح تطبيق آخر وتركه: تعود الساعة بعد دقيقتين.
- [ ] «رجوع» ٥ مرات يخرج، ولا تعود الساعة حتى إعادة التشغيل.
- [ ] «جعلها الشاشة الرئيسية»: زر Home يعيد الساعة.
- [ ] «تثبيت الشاشة»: لا يمكن الخروج بأزرار النظام؛ والإلغاء يعمل.
- [ ] الطولي والعرضي (إن كان الجهاز يدور).
- [ ] رابط خادم المسجد (إن وُجد): يفتح من الخادم، وعند إطفائه تعود الساعة المضمّنة.

## جوال المصلي
- [ ] أول تشغيل: «جوال المصلي» مقترح.
- [ ] تفعيل التنبيهات يطلب إذن الإشعارات (أندرويد ١٣+).
- [ ] أندرويد ١٤+: زر «السماح بالمنبّهات الدقيقة» يفتح الصفحة الصحيحة، ثم يختفي التحذير.
- [ ] «تجربة التنبيه» تُظهر إشعاراً بصوت.
- [ ] **أغلق التطبيق من قائمة التطبيقات الأخيرة**، وانتظر تذكير ما قبل الأذان والأذان: يصلان في وقتهما.
- [ ] أعد تشغيل الجوال: يستمر التنبيه دون فتح التطبيق.
- [ ] تغيير صوت قناة «الأذان» من «أصوات التنبيه».
- [ ] شاومي/هواوي/أوبو: بعد «استثناء البطارية» و«التشغيل التلقائي» تصل التنبيهات ليلاً.
- [ ] القبلة وتحديد الموقع، والمصحف والتفاسير بلا إنترنت.

## التابلت
- [ ] بالعرض: عمودان (الصلاة القادمة | الجدول). بالطول: عمود واحد بخط أكبر.

## جهاز قديم (أندرويد ٧ أو ٨)
- [ ] يُثبّت ويفتح. إن ظهرت رسالة «يلزم تحديث محرّك العرض» فحدّث Android System WebView من المتجر.

أرسل لي أي بند لم ينجح مع اسم الجهاز وإصدار أندرويد (يظهران في الإعدادات ← قسم التشغيل التلقائي).
